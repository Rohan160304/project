JiNANAM — Member Panel Backend APIs Reference

Complete Exhaustive List of Backend API Endpoints (`/api/v1/*`) for the Member App & Web Portal

Generated: July 31, 2026 Target Platform: Member App & Web Portal Base Route: `/api/v1`
1. Authentication & Identity Management
Method Endpoint Description
POST /auth/check-identity Checks if mobile/email exists & returns permitted auth methods (`mobile_otp`, `email_otp`, `google`).
POST /auth/request-otp Triggers MSG91 SMS / WhatsApp 6-digit OTP verification code.
POST /auth/verify-otp Verifies 6-digit OTP and returns `registrationToken` or JWT auth tokens.
POST /auth/register Registers Jain (`JFJM108`) or Non-Jain (`JFNJM108`) member profile with 21/22-section specifications.
POST /auth/login Standard credential/OTP login for members.
POST /auth/refresh Refreshes expired JWT access tokens.
POST /auth/logout Revokes current device session and clears local tokens.
GET /auth/me Fetches active logged-in member session, digital ID, and status.
2. Member Homepage & Universal Search
Method Endpoint Description
GET /dashboard/member Aggregates 15 dashboard blocks (active bookings, followed entities, upcoming events, monk location).
GET /search/universal Universal search across Temples, Dharamshalas, Monks, Events, & Members by Unique ID or keyword.
3. Member Profile & Family Account Linking
Method Endpoint Description
GET /member/profile Fetches full member profile, completion %, digital ID, and badges.
PUT /member/profile Updates personal, address, health, professional, or privacy preference fields.
POST /member/family Adds a family member with duplicate mobile check and automatic account linking.
GET /member/digital-id Returns signed JWT digital token & printable QR pass data.
4. Community Feed & Priority Visibility Engine
Method Endpoint Description
GET /feed Fetches community feed post list filtered by 6-level visibility engine (Priority 1: Followed Entities).
POST /feed Creates a new member post/update (Jain members).
POST /feed/:id/like Toggles like/applause on a feed post.
POST /feed/:id/comment Adds a comment to a feed post.
POST /feed/follow Toggles follow/unfollow status for Temples, Monks, Dharamshalas, or Community Pages.
GET /feed/following Returns list of all entities followed by the logged-in member.
5. Temples, Stanaks & Jain Centres Directory
Method Endpoint Description
GET /temples Lists Derasars (`JFJT`), Stanaks (`JFSK`), & Jain Centres (`JFJC`) with filters.
GET /temples/:id Returns detailed temple info, Puja/Pakshal timings, Dhaja history (25 yrs), and Chaturmas history.
POST /temples/:id/reviews Submits a 1–5 star rating and review.
GET /temples/:id/reviews Retrieves public reviews and official temple replies.
6. Dharamshala, Accommodation & Room Bookings
Method Endpoint Description
GET /dharamshalas Lists Dharamshalas (`JFD108`) with live availability status (*High Availability*, *Limited*, *Full*).
GET /dharamshalas/:id Fetches room types (AC, Non-AC, Dormitory, Hall), check-in/out times, and Bhojanshala rules.
GET /bookings Fetches all member bookings (Stays, Halls, Bhojanshala, Events, Tours) grouped as *Upcoming*, *Active*, *Past*.
GET /bookings/:uid Fetches single booking details, status timeline, and payment countdown timer.
POST /bookings Submits a new room / hall / stay booking request.
POST /bookings/:uid/payment-proof Uploads payment screenshot + transaction reference number.
POST /bookings/:uid/extend Requests stay extension for active accommodation.
POST /bookings/:uid/cancel Submits a booking cancellation request.
GET /bookings/:uid/receipt Downloads auto-generated Tax / Booking / Stay Receipt PDF.
7. Maharaj Saheb & Sadhvi (MS) Tracking
Method Endpoint Description
GET /monks Lists Monks (`JFMS108`) with live status (*Staying*, *Vihaar*, *Chaturmas*).
GET /monks/:id Fetches monk profile, Guru Parampara tree, Vihaar Group (`JFMSV108`), Pravachan timings & Tapasya history.
GET /monks/:id/chaturmas Returns year-wise Chaturmas history synchronized with hosting Derasars.
8. Events, Tours & Passes
Method Endpoint Description
GET /events Lists upcoming, ongoing, and past events/tours.
GET /events/:id Fetches detailed event schedule, venue, & organizer details.
POST /events/:id/rsvp Submits RSVP / Ticket booking for an event or tour.
GET /events/:id/pass Generates downloadable Event Pass / E-Ticket with QR Code.
9. Donations & 80G Tax Receipts
Method Endpoint Description
GET /donations/targets Fetches bank, UPI ID, donation categories, and 80G/CSR eligibility for a target organization.
POST /donations/manual Creates manual donation record and returns payment transfer instructions.
POST /donations/:uid/proof Uploads donation payment proof screenshot.
GET /donations Fetches member donation history with financial-year totals.
GET /donations/:uid/receipt Downloads official 80G tax receipt PDF.
10. News, Announcements & Offers
Method Endpoint Description
GET /news Fetches verified Jain news articles & announcements.
GET /offers Lists active merchant & community member offers/discounts.
11. Support Tickets & Report Incorrect Information
Method Endpoint Description
POST /support/tickets Creates a new Support Ticket (or auto-triggered from *Report Incorrect Info* on any profile page).
GET /support/tickets Lists all member support tickets and tracking status (*Open*, *In Progress*, *Resolved*).
